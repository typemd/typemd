# Onboarding

Import existing markdown collections into a structured typemd vault.

## Steps

1. **Load vault-guide** — run `/typemd:vault-guide` to get the full typemd reference
2. **Get onboarding instructions** — run `tmd instructions onboarding` to get JSON with instructions and vault context
3. **Follow the instructions** — parse the returned JSON and follow the `instructions` field exactly
